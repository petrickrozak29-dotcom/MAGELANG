# MAGELANGVERSE.ID

Smart Tourism & Digital City Platform for Magelang.

## Arsitektur Sistem

- Frontend: Next.js 15, TypeScript, Tailwind CSS, Shadcn/UI, Leaflet.js
- Backend: Node.js, Express.js, JWT Authentication, REST API
- Database: PostgreSQL + Prisma
- Storage: S3 / MinIO + Cloudinary
- AI: OpenAI API, RAG

## Modul Utama

- Landing Page
- Wisata
- Kuliner
- Budaya
- Sejarah
- Event Kota
- AI Travel Assistant
- Smart Map

## Struktur

- `frontend/` : aplikasi Next.js
- `backend/` : API Express
- `backend/prisma/` : skema database

## Catatan

Ini adalah boilerplate awal untuk presentasi smart city Magelang. Fitur inti dapat dikembangkan lebih lanjut dengan integrasi data nyata, autentikasi, dan AI Assistant.
